# 叽咕一会 · 海尼曼GK测试版

本版仅使用本次提供的海尼曼GK素材。原117本不出现在新版书架、推荐、收藏入口或小词本里，原阅读记录不做不可逆清空。

## 本版内容

- 70本绘本，每本保留8个正文／故事跨页，共560幅；另有70张封面。
- 70段整本朗读。69个WMA和1个MP3已处理为手机通用的MP3，并完整解码校验。
- 69首唱读。缺少《The Park》，该书正常共读，暂不出现唱读按钮。
- 每本含故事梗概、3个重点词、高频启蒙句型与亲子问答、2条启蒙目标、1个亲子共读小任务。
- 中文辅助、关键词定位、收藏、小词本、阅读进度、中英文搜索、按年龄与接触阶段推荐。

## 音频对应依据

绘本和普通朗读先按书名、原书编号对应，再与每本PDF的内嵌录音比较音频能量包络。70组相关系数均不低于0.98907。该方法不等同于逐字转录。

唱读包按难度重新编号，与PDF编号不同，本版按书名匹配。原书《Hop Hop Hop》的封面是Level B，普通朗读文件名却写了A，产品采用PDF封面的B。

普通录音属于整本录音，不冒充逐页录音。阅读时可以手动翻页，录音持续播放；“本页设备朗读”和小词本里的单句朗读使用设备语音，并明确标注。

## 唱读与自动翻页

读完一本后，页面提示“和叽咕唱一遍”。点击进入全屏唱读；设备不支持系统全屏时，仍以覆盖浏览器内容区的全屏页面展示。

- 前奏展示封面，歌词开始后显示对应正文跨页。
- 页面以音频实际播放时间查找时间轴；暂停、拖动进度、重头唱和恢复播放均重新计算画面。
- 时间轴采用本地模型对歌词和音频进行交叉注意力／DTW对齐，不按总时长均分。
- 《Out to Play》等歌曲改写或省略原书部分句子，独立维护唱读字幕；没有唱词的短画面间隔不伪造歌词。
- 《The Hat》的“Pop!”及部分歌曲开头的前奏吞并问题已通过独立转录检查修正。
- 时间轴经过结构和定点转录复核，尚不等于69首全部经过真人听感验收。建议优先试听《At the Market》《My Big Bear》《The Hat》《Out to Play》，再按实际反馈微调。

## 文件与运行

产品测试包为已经构建好的网页版本，包含全部图片、音频和时间轴，不依赖外部图片链接。解压后，在目录中运行：

```bash
python start.py
```

打开终端显示的本地地址。此服务只监听本机，支持MP3拖动所需的HTTP字节范围请求。不要把本地文件服务器当成线上部署。

用户已明确授权将图文、朗读、唱读及完整新版产品代码公开上传并发布。本次也未修改独立的微信原生小程序代码。

## 数据与维护

- `books/catalog.js`：页面内容、共读指南、普通录音及唱读时间轴。
- `books/singing.js`：按音频时间查找页面的纯逻辑。
- `books/library/heinemann-gk-XX/`：封面、正文图片与两类音频。
- `content/heinemann-gk/editorial.tsv`：逐本编辑内容。
- `content/heinemann-gk/translations.tsv`：逐页中文辅助。
- `content/heinemann-gk/pairing-manifest.json`：普通音频匹配证据。
- `content/heinemann-gk/singing-index.json`：69首唱读的时间轴、歌词及调整说明。
- `content/heinemann-gk/import-report.json`：缺失文件与分级修正。

原PDF、原始朗读压缩包与唱读压缩包均保持不变。原书署名和版权说明保留；本版没有把它们标成开放许可素材。

## 验证范围

内容检查覆盖70本书、630张JPEG、70段普通朗读、69首唱读、全部五项共读内容以及关键词回到原页的定位。

交互检查覆盖旧书退出书架、双语搜索、收藏和小词本、阅读页位置保持、整本录音在翻页时持续、唱读暂停、回拖、重播和退出。

手机浏览器的系统全屏策略、声音权限和设备语音质量，仍会因iOS／Android设备而不同；不支持系统全屏时使用页面全屏。
