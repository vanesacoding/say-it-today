## 配音入选规则

音色名单见 reading-voice-profiles.json：美式 Charlie、Rowan；英式 Charlotte、Knightley。供应商官方目录已核验口音和用途。除 Charlie 已获用户认可外，其他均为待试听候选，不能声称已验证自然度或逐页发音。

- 当前已认可录音保留；不因扩充重复收费生成。
- 新音色先用相同短段试听，再配新书；每本书固定一个旁白与一种口音。
- 审核重音、连读、疑问语调、专名、复数、过去式以及数字；不能靠调高音调把成人声假装成童声。
- 只在有可靠元数据并核验实际音频后标“美式英语 / 英式英语”。现有其他来源的录音不得按出版地或引擎名称猜口音。
- 日常界面不重新显示真人/AI来源；合成来源和创作署名仍保留在说明页。
- 新音色的 API 权限、语速和实际样本未验收前，不批量生成 50 本，不把“官方支持某口音”等同于每页绝对无误。
