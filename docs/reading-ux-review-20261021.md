# 阅读与小词本体验检查（2026-10-21）

范围：小书架选书 → 阅读 → 读完 → 小词本详情 → 查看原句 → 返回原词。检查对象为当前仓库构建的真实页面，使用 Chromium 触摸事件和页面截图；受已有浏览器访问限制，本轮没有直接操作线上站点，也没有将其称为真机验收。

## 发现与改动

| 步骤 | 检查结果与修复 | 验证 |
| --- | --- | --- |
| 1. 书架与阶段 | 系统原生选择弹窗字体和底色与 App 不一致。改为暖米色内置面板、13px选项与原生单选控件；选择当前项也收起，焦点返回入口。 | 主题×阶段筛选、刷新重置、截图与字号/颜色检查。 |
| 2. 阅读 | 原竖版图片占满页面高度，翻页后还沿用滚动位置。新增绘本按英文、中文及控件实际占用高度分配图片区；翻页归顶。 | 105页×4个尺寸，开启陪读，测量文字与底部控件是否重叠。 |
| 3. 阅读手势 | 原来只在图片区有效，手势翻页会中断“听故事”。扩展到非按钮的阅读区域，手动翻页接续正在播放的故事；首页向右滑不打断朗读。 | 原生触摸、上下滚动隔离、取消/多指/小幅滑动、音频旧回调检查。 |
| 4. 读完与原图 | 保留上一轮的小鸟和单行词条；适屏图提供“看全图”，完整原画和英文均未改写。长面板关闭栏保持可见。 | 单词长度、原画入口及固定翻页检查。 |
| 5. 小词详情 | 小词本和绘本内的小词均可左右切换，也提供前后按钮、位置和键盘方向键；首尾不循环。 | 浏览不改变复习评分，切词停止上一词音频。 |
| 6. 返回 | 原句返回保留原词和词序；从书籍回书架保留主题与阶段下的浏览位置。 | 原生触摸回路和滚动位置回归测试。 |

## 已确认的手机布局结果

开启中文陪读后：390×844为105/105页一屏显示；430×932为105/105；320×568为102/105。小屏的其余3页允许滚动，英文与提示没有被截断。后续最终 CI 还检查1024×768布局。

## 证据与限制

基线截图来自本轮 CI [39459008930](https://github.com/vanesacoding/say-it-today/actions/runs/39459008930) 的完整原画阅读状态；阶段弹窗问题另由用户当前截图确认。修改后截图与触摸证明保存在 PR30 的 `phone-book-layout-proof` 工件中，包括阶段选择器、书架、阅读、读完、小词详情及原句。

一屏展示通过适屏显示框和内容测量实现，没有裁掉故事人物或关键物品。低清原图仍受来源分辨率限制，本次未宣称修成高清。截图与自动化测试不构成完整屏幕阅读器或 iOS/Android 真机认证。
