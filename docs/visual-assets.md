# Fruit photographs

The jackfruit image is cropped from the visual reference video supplied by the project owner for this implementation (1000045314.mp4).

All other fruit photographs are from the Fruit-Images-Dataset by Horea Muresan and Mihai Oltean:
https://github.com/Horea94/Fruit-Images-Dataset

Original folder mappings: Pitahaya Red (dragon fruit), Lychee, Mangostan (mangosteen), Rambutan, Passion Fruit, Papaya, Pomegranate, Guava, Avocado ripe, Fig, Kaki (persimmon), Kumquats, Nectarine, Apricot, Grapefruit Pink, Quince, Cantaloupe 1, Tamarillo, Salak, Kiwi, Pineapple, Raspberry.

License: MIT. Full license below.

Audio: pre-generated neural speech, voice en-US-JennyNeural, with edge-tts. These are synthesized recordings, not recordings of a human speaker. Each file speaks the matching English word.
