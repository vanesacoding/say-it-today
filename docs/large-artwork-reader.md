# 大图阅读页

阅读图片按阅读区宽度显示，保留原图比例，不再通过压缩图片高度让英文、陪读提示和操作同时塞进首屏。长图与长文字通过纵向滚动阅读，底部翻页操作固定显示。

- 手机端取消图片两侧的阅读区内边距；英文和陪读提示保留独立留白。
- 大屏阅读区最大宽度 820px，退出阅读后恢复原页面宽度。
- 图片不裁切；原有分镜绘本保留既定分镜与原跨页入口。
- 翻页从页面顶部开始；保留陪读开关、配音、收藏、阅读进度和返回行为。
- 页面底部留出操作栏及安全区空间，滚动至底部可完整看到文字和朗读操作。

微信原生迁移时应采用同样的展示原则：图片组件使用 `mode="widthFix"`，图片宽度占满阅读区，不设基于剩余屏高的高度上限；正文和陪读提示放在图下；固定翻页栏并预留底部安全区。本次仓库修改针对 PWA，未修改独立微信原生项目。

自动检查：`node scripts/check-large-reader.mjs` 验证 DOM/CSS 与阅读交互；`node scripts/check-large-reader-layout.mjs` 在既有 CI 的媒体准备和本地服务后验证四种视口的真实几何尺寸、原图比例、底部内容可达性和翻页位置。后一项不应以 jsdom 结果替代。
