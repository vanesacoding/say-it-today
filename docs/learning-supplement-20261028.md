# 闪卡主题与自然拼读更新

2026-10-28，基于用户提供的闪卡音频补充和牛津树自然拼读压缩包。

## 使用方式

- 闪卡：399张按15个主题归类，原书级别作为独立筛选。看图翻卡和听音找卡使用整个选定范围，取消5张一轮的限制；全部主题按主题顺序排列。
- 自动快闪：1.5 / 2.5 / 4秒，支持暂停、原声开关、循环、前后切换。长录音播放完再翻卡；音频失败暂停并提示重试；退出和切后台取消播放及计时。自动浏览只记录看过，不代替用户选择是否认识。
- 图片：闪卡按阅读区宽度放大，快闪与答案面展示完整原卡；猜词面继续隐藏底部答案。手机端取消额外横向留白，大屏最大620px。
- 音频：按稳定卡片ID或严格规范化后的相同词句匹配333张卡，保留每一项来源与SHA256。66张未找到可靠匹配，界面标明暂无原声。未将没有配套图片的音频生成虚构闪卡。
- 自然拼读：66本，Level 1+–5各12本，Level 6共6本，完整保留1192页原图。提供级别筛选、英文书名搜索、大图阅读、页码目录、手动翻页、整本原声及可拖动进度，独立保存书页和音频位置。
- 原声没有已核对的逐页时间轴，因此由读者边听边翻页。保留原版页面中的拼读和家长指导，不虚构逐页中文、拼读规则或自动对齐。

## 导入与发布

导入命令：

```sh
python scripts/import-learning-supplement.py --flashcards /path/to/闪卡音频补充.zip --phonics /path/to/自然拼读-牛津树.zip
```

需要 PyMuPDF、Pillow、ffmpeg、ffprobe；可用 `FFMPEG`、`FFPROBE` 指定路径。PDF转换为最大1200px宽的WebP，优先利用PDF内嵌图像分辨率；原声转单声道64kbps MP3。匹配报告在 `content/learning-supplement/`。PDF中的正文是素材，不执行其中的操作说明。

原始编号存在交叉，尤其Level 4的Craig、Knight、Lost Chimp、Painting几本，按书名配对，保留源文件名。Cruch/Crunch、Rook/Rock等文件名拼写差异通过明确别名核对，不按相似编号盲配。

媒体随站点发布并按需缓存，不加入整库预缓存。保留海尼曼70本现有目录、阅读存储和闪卡历史存储键；自然拼读使用独立存储键。

## 验证

- `npm run check`：原有内容与进度检查，媒体完整性、全部补充录音解码、来源摘要，以及主题范围、超5张连续浏览、快闪计时/暂停/错误重试/过期回调、自然拼读的进度、原声、目录和原70本回归。
- `npm run build`：正式站点构建。
- `node scripts/check-learning-layout.mjs`：320×568、390×844、430×932、1024×768真实浏览器，图片尺寸、溢出、真实MP3播放与拖动、快闪、切后台暂停和刷新恢复。通过 `LEARNING_URL` 可针对线上站点复验。
