# 叽咕一会：绘本年龄推荐

- 产品名为「叽咕一会」，仓库与 Pages 路径保持 say-it-today。
- public/books/ages.js 按绘本 ID 保存 ageBands，并在目录载入后赋给各绘本；与 stageId 英语难度独立。
- 年龄分为 0–2、3–4、5–6、7+。这是叽咕根据题材、情节理解与共读方式制定的编辑推荐，不是出版社的年龄分级。
- 年龄标签不展示在书架卡片、详情和阅读页；用户仍可在「我的 → 宝宝的共读偏好」设置年龄及阅读阶段。
- 首页优先继续最近未读完的绘本，保留现有进度。没有未读完的书时，推荐同级别、年龄标签匹配的绘本；同池优先未读，再按精选顺序与句长排序。
- 没有相应年龄的同级别绘本时，在所选级别中按年龄段距离选最近的书；不会把家长主动选择的高级别强制降级。
- 小书架保持完整可浏览；年龄是推荐条件，不是访问限制。
- 新增或替换绘本需要同步年龄映射。npm run reading:check 中的 check-book-ages.mjs 校验全部在架绘本、12 种年龄与级别组合、回退、未读优先及标签隐藏。
